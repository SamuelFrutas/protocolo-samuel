# Protocolo Samuel

Repositório oficial das regras de planejamento, desenvolvimento, continuidade e entrega dos sistemas de Samuel.

## Documento principal
- [Protocolo Oficial de Desenvolvimento Samuel — v1.3](./PROTOCOLO_OFICIAL.md)

## Como usar
Todo novo projeto e todo novo chat de desenvolvimento deve consultar o protocolo e manter os arquivos de controle `.project/` no repositório do sistema.

## Regras essenciais
- Planejamento por etapas e barra de progresso verificável.
- Protótipo navegável hospedado para aprovação antes do desenvolvimento funcional.
- Documentação de continuidade no repositório de cada sistema.
- Comunicação curta e execução contínua dentro das capacidades disponíveis.
- Administração do GitHub autorizada para tarefas técnicas rotineiras; operações irreversíveis de alto impacto exigem confirmação.
- Deploy em produção exige autorização explícita por projeto.
